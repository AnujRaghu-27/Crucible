# Crucible

Crucible is a platform for comparing different handwriting recognition systems.

The idea is simple: take the same handwritten student answer and give it to different handwriting recognition systems. Crucible collects the results so they can be compared in one place.

## What is the problem?

There are many systems that can convert handwriting into digital text, but their results can be different when given the same handwritten answer.

For example, the same handwritten answer could be processed by:

- Google Document AI
- Azure Document Intelligence
- Amazon Textract
- PaddleOCR
- Transkribus

Each system may recognize the handwriting differently.

Instead of testing these systems separately, Crucible provides one place to test them using the same handwritten answers.
